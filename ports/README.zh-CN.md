# 平台适配

[English](README.md)

ChronoPipe 核心不包含操作系统、Socket、凭据或设备驱动代码。一个平台集成需要提供：

- 推入完整 `cp_frame_t` 样本行的采集回调；
- 调用方拥有的 arena 与 recorder/store 缓冲区；
- 与存储介质对齐的 `cp_flash_io_t` 读、写和擦除函数；
- `cp_batch_transport_t` 发送器，以及应用层对确认消息的处理路径；
- 可选的 COBS 实时字节流输出；
- 单调微秒时钟；如有需要，还应单独记录墙钟映射事件。

请保持 ISR 工作有界：ISR 应只负责打时间戳并入队，或填充预分配槽位；图执行、记录封块、擦除和网络工作应放在由产品自行确定优先级的应用任务中。
